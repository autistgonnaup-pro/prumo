Aqui está o conteúdo pronto para você copiar e colar no seu arquivo `comandos.md`. Ele está formatado e organizado para servir como um guia rápido de consulta para o seu projeto.

Crie um arquivo chamado **`comandos.md`** na raiz do seu projeto e cole o texto abaixo:

```markdown
# 🛠️ Guia de Comandos - Monitor de Arquivos (Supabase)

Este guia contém os comandos necessários para gerenciar e testar o script de monitoramento de arquivos (`watch-files.js`).

---

## 🚀 1. Iniciar e Parar o Monitoramento

**Iniciar o monitor (deixar rodando):**
Recomendado usar o arquivo `.bat` com duplo clique. Se for pelo terminal:
```bash
node watch-files.js
```
*Ou, usando o atalho do Windows:*
```bash
start iniciar-monitor.bat
```

**Parar o monitoramento:**
No terminal onde ele está rodando, aperte:
```text
Ctrl + C
```
*(Se estiver rodando pelo `.bat`, basta fechar a janela preta do CMD).*

---

## 📋 2. Listar Arquivos no Supabase

Para ver os arquivos salvos (abra uma nova aba do terminal):
```bash
node watch-files.js list
```

---

## 🧪 3. Testar Criação e Exclusão (Terminal)

Com o monitor rodando em uma aba, abra outra aba para testar:

**Criar um arquivo de teste:**
```bash
echo "teste" > arquivo-teste.txt
```

**Excluir o arquivo de teste:**
```bash
rm arquivo-teste.txt
```
*(No CMD tradicional do Windows, o comando é `del arquivo-teste.txt`).*

---

## 📦 4. Instalar Dependências

Se precisar reinstalar o projeto em outro computador:
```bash
npm install
```
Ou, para instalar especificamente as dependências do script:
```bash
npm install dotenv @supabase/supabase-js chokidar
```

---

## 🔐 5. Segurança e Variáveis de Ambiente

O arquivo `.env.local` **NUNCA** deve ser commitado no Git. Certifique-se de que ele está listado no seu `.gitignore`.

**Estrutura correta do `.env.local`:**
```env
VITE_SUPABASE_URL="sua_url_do_projeto"
VITE_SUPABASE_PUBLISHABLE_KEY="sua_chave_publica"
SUPABASE_SECRET_KEY="sua_chave_secreta_aqui"
```

---

## 💾 6. Comandos do Git (Commit)

Para salvar o progresso no Git:

**Ver o que foi alterado:**
```bash
git status
```

**Adicionar alterações:**
```bash
git add .
```

**Salvar o commit:**
```bash
git commit -m "feat: adiciona monitoramento de criacao e exclusao de arquivos"
```

---

## ⚠️ 7. Manutenção no Banco de Dados (Supabase)

Se precisar recriar a tabela, rode este SQL no **SQL Editor** do Supabase:

```sql
-- Cria a tabela de controle
create table public.arquivos_novos (
  id bigint generated by default as identity primary key,
  caminho text not null,
  criado_em timestamptz default now()
);

-- Impede que o mesmo arquivo seja salvo duas vezes
alter table public.arquivos_novos add constraint caminho_unico unique (caminho);
```
```
